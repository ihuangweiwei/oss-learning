# oss-intel · AI 情报站 Skill

> 把技术雷达的亮点变成对外传播的每日快讯。本技能承接 oss-learning-maintainer 维护循环的 Step 4.5。
> 情报站是**流量盘子**，不是技术笔记——每篇快讯都要能回答"读者看完该不该用/该不该关注"。

## 1. 快讯格式（固定）

`docs/intel/YYYY-MM-DD.md`，固定四段：

1. **① 头条**（1–2 条真正有增量：新模型 / 新框架 / 重大发布——没有真增量就不硬写头条）；
2. **② 飙升项目盘点**（表格：仓库 | ⭐ | ⭐/天 | 一句话 | 适合谁；来自雷达维度③）；
3. **③ 本期接入清单**（manifest 新增的仓库，一句价值）；
4. **④ 变现提示**（结尾挂三条变现链路：赋能企业 / 接单交付 / 流量内容）。

## 2. 编辑方针（写作方向把关，必须遵守）

1. **有选型价值**：读者看完能回答"我该不该用"。禁止纯罗列/凑数/填日期。
2. **快讯格式固定**：按上节四段，不乱加栏目。
3. **信息可验证**：⭐、license、owner、日期必须真实（来自 GitHub API/页面），不写"感觉值"。
4. **观点有依据**：说"值得关注"必须给理由（场景/生态/赚钱链路）；不标题党、不夸大数字。
5. **结尾挂变现链路**：每条头条/盘点落到 赋能企业 / 接单 / 流量 之一。

## 3. 流量策略

| 受众 | 内容 | 渠道 |
|---|---|---|
| 找 AI/开源新框架的开发者 | 技术雷达 · 每日快讯 | GitHub、掘金、知乎 |
| 企业架构师 / 技术决策者 | 微服务蓝图 · AI 平台蓝图 | 搜索引擎长尾、公众号 |
| 想做副业/接单的人 | 接单项目盘点 · 变现路径 | 掘金、知乎、公众号 |
| 备战面试的人 | 技术面试小册（二期项目） | 掘金、GitHub、公众号 |

运营节奏：**每日快讯 → 每周《开源精选》汇总 → 每月《AI 开源月报》**。Pages 当内容仓库，公众号/掘金当分发渠道。

## 4. 更新索引

写完快讯后更新 `docs/intel/index.md`：把当日快讯加进「快讯索引」顶部，必要时更新「专题收藏」。

## 5. 产物与入口

- 快讯：`docs/intel/YYYY-MM-DD.md`
- 索引/方针/策略：`docs/intel/index.md`
- 雷达原料：`docs/tech-watch/`（由 oss-radar 产出）
